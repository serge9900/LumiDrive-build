# LumiDrive v0.7.5 — Test of the built-in updater

> **Experimental test release.** This is intentionally published as a regular GitHub Release, **not a prerelease**, because LumiDrive's updater ignores GitHub prereleases.

## What's new

- Version-only bump from **LumiDrive 0.7.4 (286)** to **0.7.5 (287)**.
- **No feature, media, UI, Android Auto or updater-code changes** compared with 0.7.4.
- Published specifically to verify that **Settings → Other → Check for LumiDrive updates** in **v0.7.4** discovers **v0.7.5**.
- APK built by GitHub Actions; release includes the arm64 APK and SHA256SUMS.txt.

## How to test

1. Install **LumiDrive 0.7.4** on your phone (the version from the v0.7.4 GitHub Actions run).
2. Open **Settings → Other → Check for LumiDrive updates**.
3. **Expected:** a dialog offering **0.7.5**, followed by the standard Android APK installation prompt after confirmation.
4. If it still says no updates, open **Settings → Other → View LumiDrive log** and share the redacted update-related entries for diagnosis. Do **not** publish log files without inspecting for private IPTV links or tokens.

Please **do not uninstall** 0.7.4 when testing; an in-place update preserves the installed app's settings as long as signing and package ID match.

## Русский

Это **тестовый релиз LumiDrive 0.7.5**, созданный специально для проверки обнаружения обновления **из установленной 0.7.4**.

- Изменён только номер версии: **0.7.5 (287)**.
- Воспроизведение IPTV, Android Auto, браузер и сам механизм обновления не изменены.
- В установленной 0.7.4 открой **Настройки → Другое → Проверить обновления LumiDrive**.
- Ожидаемый результат: предложение обновиться на **0.7.5**.
- Если обновление не обнаружено, сообщи результат и пришли диагностические записи из LumiDrive.log (предварительно проверь их на наличие личных данных).

**Не удаляй приложение перед установкой новой версии.**
