# LumiDrive v0.7.6 — Branded update icon

> Experimental Android / Android Auto build. This release is published for testing the built-in update process and updated LumiDrive branding.

## What's new
- Replace the old small Fermata icon in the **Update available** confirmation dialog with the branded LumiDrive **L** mark in violet, cyan and pink.
- Keep the tested GitHub Releases update checker, version comparison, SHA-256 verification, Android system installer, IPTV player, browser, and Android Auto behavior unchanged.
- Version **0.7.6 (288)**, application ID **com.lumi.drive.auto**.
- Includes all improvements through LumiDrive 0.7.5.

## How to update
1. From an existing LumiDrive **0.7.4 or 0.7.5**, open **Settings → Other → Check for LumiDrive updates**.
2. Confirm the offer to install **0.7.6**.
3. Accept the Android installer prompt. Do not uninstall your current installation before updating.

For direct installation, download **LumiDrive-v0.7.6-arm64.apk** under Assets. This APK is intended for supported arm64 Android devices.
