# LumiDrive 0.7.10 — Reliable update checks and log export

- Update checks use the platform HTTP stack, bounded timeouts and up to three attempts for transient failures.
- Incomplete responses report a failure instead of appearing as no update. Repeated taps do not start overlapping checks in the same activity.
- Metadata loading uses a private list isolated from progress observers.
- White text in diagnostic category lists, log viewer and dialog buttons.
- Download log in each category saves the displayed filtered, redacted snapshot through Android's file picker.
- YouTube playback, audio focus and camera interruption behavior are unchanged.
