# LumiDrive v0.7.8 — Branded APK download notification

LumiDrive **0.7.8 (290)** is a focused Android UI maintenance release that corrects the icon shown while the app downloads an update.

## Changes

- **Download progress notification:** The notification that says “Downloading https://github.com...” / “Скачивание https://github.com...” now displays LumiDrive's white **L + play** symbol instead of the old Fermata symbol.
- A dedicated **24dp transparent-background monochrome vector** follows Android's status-bar notification icon requirements and adapts to system tinting.
- **Update confirmation dialog** still uses the previously added branded LumiDrive icon.
- The Google home page on the Browser card and proper `LumiDrive-vX.Y.Z-arm64.apk` update filenames from v0.7.7 are preserved.
- No changes to APK download transport, GitHub Release discovery, SHA-256 validation, Android installer, IPTV player or Android Auto.

## Installation and verification

1. On **LumiDrive 0.7.7**, open **Settings → Other → Check for LumiDrive updates**, then confirm installing **0.7.8**, or install the official APK asset on top of the existing app.
2. The **0.7.7 app's download notification** may still display Fermata while fetching this update — that's expected because the old installed app creates that notification.
3. The new LumiDrive progress icon takes effect **for downloads started after 0.7.8 is installed**. Verify on a future update or another download using the app's built-in downloader.

**Do not uninstall** the existing version before updating; your IPTV playlists and app settings should be retained when APK signatures match.

## Русский

**LumiDrive 0.7.8 (290)** исправляет иконку в уведомлении о скачивании обновления.

- Вместо Fermata отображается фирменный монохромный значок LumiDrive с буквой **L**.
- Для Android используется отдельная белая иконка 24dp с прозрачным фоном.
- Кнопка **«Браузер»** с Google, корректное название скачанного APK, проверка SHA-256, IPTV и Android Auto остаются без изменений.

**Важно:** при переходе с 0.7.7 на 0.7.8 уведомление ещё может показывать старую иконку, так как скачивание выполняет установленная 0.7.7. Новая иконка будет видна в следующих загрузках уже из 0.7.8.
