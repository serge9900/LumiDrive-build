# LumiDrive v0.7.7 — Browser home page & update filename

LumiDrive **0.7.7 (289)** is a focused maintenance release for the Android Auto/phone APK (`com.lumi.drive.auto`).

## What changed

- **Browser card:** Tapping **Browser / Браузер** from the LumiDrive main screen now opens **https://www.google.com/** instead of a blank page. Existing browser navigation, bookmarks, Google searches, WebView features and saved history continue to work.
- **APK download name:** The built-in updater now names the downloaded file from the verified GitHub Release asset, for example `LumiDrive-v0.7.7-arm64.apk`, rather than `Fermata-<random digits>.apk`.
- **File safety:** If the exact file already exists in public Downloads, the updater does not overwrite it; it uses the app's own update cache instead.
- The first-party GitHub Releases update checker, SHA-256 verification, Android system installer, current package name/signing, IPTV playback and Android Auto logic are unchanged.

## Installation

1. In your existing **LumiDrive 0.7.6**, open **Settings → Other → Check for LumiDrive updates**.
2. Choose to update to **0.7.7** and confirm the standard Android installer prompt.
3. Test Browser from the LumiDrive dashboard and the downloaded APK name when updating.

You can alternatively install the `LumiDrive-v0.7.7-arm64.apk` asset below **on top of the installed version**. Don't uninstall your working installation: this may erase saved IPTV sources and preferences.

## Русский

**LumiDrive 0.7.7 (289)** — исправление двух ошибок:

- При нажатии на **«Браузер»** с главного экрана сразу открывается **https://www.google.com/**, а не пустая страница.
- При загрузке обновления имя файла теперь формируется по релизу, например **`LumiDrive-v0.7.7-arm64.apk`**, вместо старого **`Fermata-...apk`**.
- Если такой файл уже находится в «Загрузках», он не будет перезаписан.
- IPTV, Android Auto, проверка SHA-256 и процесс установки через Android остались без изменений.

Для обновления из 0.7.6 выбери **Настройки → Другое → Проверить обновления LumiDrive** и подтверди установку. **Не удаляй установленную версию.**
