# LumiDrive 0.4 — UI implementation plan

Status: design approved; implementation in progress. Branch: `lumidrive-v0.4-ui`.

## Approved phone home screen
- Dark purple background (#10091E), violet cards, pink/cyan accents.
- Header with LumiDrive logo/name and settings access.
- Continue watching card linked to the actual recent-media action.
- IPTV, YouTube, Browser and Library cards; reuse existing navigation handlers.
- Bottom navigation for Home, Search, Favorites, Settings, with accessible focus states.

## Engineering constraints
- Keep existing playback, IPTV playlists, Browser, YouTube and Android Auto services functional.
- Never replace working entry points with decorative controls.
- Mobile and Android Auto UI must be implemented and tested separately.
- Do not disable Android Auto safety restrictions.
- Preserve GPL-3.0 notices and original source attribution in distributed source/legal notices.
- Keep the existing v0.3 workflow and main branch untouched until a successful test.
- Check upstream 2.0.2 view/layout IDs before modifying the patch script.
- Bump app version and artifact names together after code changes are validated.

## Validation checklist
- Patch applies cleanly to pinned Fermata 2.0.2.
- Gradle build succeeds; APK installs alongside original Fermata where package IDs permit.
- All four home cards navigate correctly; back, search, settings and favorites work.
- Existing IPTV playlist and playback continue to work.
- Android Auto service appears and remains operable in a parked-car test.
- No unintended legacy update prompt in the LumiDrive UI.
