# World channels — 0.7.11 test build

Open IPTV, press Add and choose World channels, or use World channels in the IPTV menu. Search for a country and select it. Its playlist is downloaded and saved as a normal IPTV source. Selecting it again reuses the source. Existing personal playlists are unchanged; choose My own playlist to add a URL or file.

Countries: bundled index from https://github.com/iptv-org/iptv/blob/master/PLAYLISTS.md, retrieved 2026-11-11. Stream lists remain remote and use the normal 24-hour playlist cache. Some streams may be unavailable or region restricted. Attribution: IPTV-org contributors, https://github.com/iptv-org/iptv (Unlicense).

Manual checks: first install; existing personal playlists; country search RU/EN; open country twice quickly; retry offline failure; re-open saved country; delete and re-add; favorites; Android Auto touch and rotary focus. No autoplay or camera/audio-focus behavior changed. This is not a published release.
