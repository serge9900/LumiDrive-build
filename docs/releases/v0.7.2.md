# LumiDrive v0.7.2 — Diagnostics and safer logs

> **Experimental Android Auto / Android media test release.** This version is published to test LumiDrive's in-app update checker. Please back up your settings and M3U sources before changing versions.

## What's new
- Privacy-aware `LumiDrive.log`: redacts common credentials, sensitive URL paths, queries and tokens before writing or sharing diagnostics.
- Log viewer in **Settings → Other → View LumiDrive log** with **All, Errors, Warnings, Android Auto, Browser and IPTV** filters.
- Copy selected log entries or share a sanitized `LumiDrive.log` copy.
- Expanded Android Auto session and media-command tracing, to diagnose unsolicited IPTV auto-resume.
- Improved WebView logging for host, error type and main-page/subresource failures, with repeated-event suppression.
- Includes previous LumiDrive 0.7.1 update-check and log-file naming fixes.

## Install / Update
- The APK is for the `com.lumi.drive.auto` Android Auto variant, **arm64**, version **0.7.2 (284)**.
- If you have LumiDrive 0.7.0 or 0.7.1 with a compatible signature, open **Settings → Other → Check for LumiDrive updates**, accept the prompt, then approve Android's installer.
- Android may request permission to install apps from this source. Approve only if you trust this repository and are intentionally updating.
- If already using v0.7.2, no newer release will be offered.
- Never uninstall a working version just to test updating: it can erase app settings and playlists.

## Security and attribution
- The APK and `SHA256SUMS.txt` are published from a previously successful GitHub Actions build; checksum and signing-certificate checks gate this release.

**LumiDrive 0.7.2** — тестовая версия с улучшенным журналом диагностики.

- Логи теперь скрывают типичные токены, пароли и закрытые части ссылок IPTV.

- Сохранены исправления проверки обновлений и журнала из версии 0.7.1.

Для проверки обновления открой **Настройки → Другое → Проверить обновления LumiDrive** в версии **0.7.0 или 0.7.1**. Приложение должно предложить **0.7.2**. Установку подтверждает стандартный установщик Android. Если уже установлена **0.7.2**, предложения не будет.

**Не удаляй старую версию перед обновлением**, чтобы сохранить настройки. Экспериментальную сборку необходимо проверять на телефоне; вождение и просмотр видео несовместимы.
