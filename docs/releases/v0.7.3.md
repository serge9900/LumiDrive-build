# LumiDrive v0.7.3 — Update dialog contrast

> **Experimental Android Auto / Android media release** — published to test the in-app updater from LumiDrive v0.7.2. Back up settings and M3U sources before updating.

## What's new

- Fixed nearly invisible **OK** and **Open APK builds** buttons in the purple **Settings → Other → Check for LumiDrive updates** dialog.
- The dialog uses readable light-cyan action text on a dark background.
- Includes all the improvements from v0.7.2: privacy-safe diagnostics, filtered `LumiDrive.log`, Android Auto event tracing, and the first-party GitHub Release updater.
- The updater still checks **this repository's official Releases**, downloads only a correctly versioned LumiDrive APK, and verifies its GitHub SHA-256 digest when present.
- IPTV, YouTube, media player and Android Auto behavior were not intentionally changed in this patch.

## Update from v0.7.2

1. Open **LumiDrive → Settings → Other → Check for LumiDrive updates**.
2. The app should offer **v0.7.3**. Confirm the update prompt.
3. Approve Android's package installer. **Do not uninstall LumiDrive first** — removing the app may erase settings and IPTV playlists.

**Android package:** `com.lumi.drive.auto`  
**Version:** `0.7.3` (`versionCode 285`)  
**Architecture:** ARM64 (`arm64-v8a`)  
**APK:** `LumiDrive-v0.7.3-arm64.apk`

If the app doesn't detect the release, you can download the APK from the assets below and install it over v0.7.2 (provided the signing certificate matches).

## Security and attribution

The release process checks the previously successful source build, APK SHA-256, Android package/version and signing-certificate compatibility against the **published v0.7.2 APK**, before making v0.7.3 public. The APK is copied unchanged from the verified build.

## 🇷🇺 Русский

**LumiDrive 0.7.3** — тестовый релиз для проверки обновления прямо из установленной версии **0.7.2**.

### Что исправлено

- Кнопки **«Открыть сборки APK»** и **«ОК»** в окне проверки обновлений теперь светло-голубые и хорошо видны на фиолетовом фоне.
- Сохранены возможности 0.7.2: диагностический журнал `LumiDrive.log`, фильтры ошибок, события Android Auto, скрытие чувствительных данных в логах.
- IPTV, YouTube, воспроизведение и Android Auto в этом изменении не затрагивались.

### Как проверить автоматическое обновление

1. В установленной **0.7.2** открой **Настройки → Другое → Проверить обновления LumiDrive**.
2. Подтверди предложение обновиться до **0.7.3**.
3. Разреши установку APK стандартному установщику Android.

**Не удаляй приложение перед обновлением**, чтобы сохранить настройки и M3U. Если обновление не обнаружится, установи APK из приложенных файлов вручную поверх 0.7.2.

Выпуск экспериментальный: совместимость с отдельными Android-устройствами и автомобильными системами требует проверки.
